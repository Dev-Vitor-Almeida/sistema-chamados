# Sistema de Chamados

Projeto desenvolvido para praticar programação e aprender a construir uma API para um sistema de suporte técnico.

## Sobre o projeto

A ideia é criar um sistema em que usuários possam registrar chamados de suporte, informar o problema e acompanhar seu atendimento.

O projeto está sendo desenvolvido por etapas, com foco no desenvolvimento backend e na integração futura com banco de dados e interface web.

## Tecnologias

- JavaScript
- Node.js
- Express
- Git e GitHub

## Funcionalidades em desenvolvimento

- [x] Criar servidor com Express
- [x] Receber chamados por meio de uma requisição POST
- [x] Retornar os dados do chamado em JSON
- [ ] Gerar um ID para cada chamado
- [ ] Listar e buscar chamados
- [ ] Editar e excluir chamados
- [ ] Integrar com MySQL
- [ ] Desenvolver a interface com React

## Como executar

1. Instale o Node.js.
2. Entre na pasta `backend`.
3. Instale as dependências:

   `npm install`

4. Inicie o servidor:

   `node api.js`

O servidor será iniciado na porta 3000.
